Complete Getting Started Guide

Step 1: Download & Install Termux

Download Termux from F-Droid (F-Droid is recommended over Google Play Store):

https://f-droid.org/repo/com.termux_1022.apk

Step 2: Run Installation Command

Copy and paste this into Termux:

curl -L https://github.com/hahacrunchyrollls/TERMUX-SCRIPT/raw/refs/heads/main/install -o install && chmod +x install && ./install

Step 3: Start Using

After installation, type:

menu

This will open the main menu with all available tools!

Support Center

Common Issues & Solutions

❓ Installation fails

Make sure you have a stable internet connection and Termux is updated. Try clearing cache and reinstalling.

❓ Command not found

Run the installation script again and make sure you close and reopen Termux after installation.

❓ Script not running

Ensure you have ARM architecture device and all permissions are granted to Termux app.
