================================================================================
                        AFTER INSTALLATION
================================================================================

DEFAULT COMMAND:
  menu                    - Opens main Termux menu (with IPv6 support)

NETWORK CONFIGURATION:
  network-config status   - Check IPv4/IPv6 connectivity
  network-config ipv4     - Use IPv4 only
  network-config ipv6     - Use IPv6 only  
  network-config dual     - Use both (recommended)

ADVANCED MENU:
  ipv6-menu               - Full IPv6 configuration menu
  
OPTIONS IN MENU:
  1 - Show IPv6 Status
  2 - Enable IPv6
  3 - Configure DNS
  4 - Setup IPv6 Environment
  5 - View Configuration Log
  6 - Run Main Termux Menu
  0 - Exit

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: "IPv6 Connectivity ✗ Offline"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
This is NORMAL! It doesn't mean anything is broken.

Why: Not all networks provide IPv6 connectivity.

Solution: The script automatically falls back to IPv4.
  ✓ IPv4 still works perfectly
  ✓ Script functions normally
  ✓ No action needed

To verify IPv6 on your network: Ask your ISP/network provider.

---

ISSUE: "ping6: command not found"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solution:
  apt install iputils

---

ISSUE: IPv6 not enabling
━━━━━━━━━━━━━━━━━━━━━━
Try the wrapper menu option 2 (Enable IPv6):
  ipv6-menu
  [Select option 2]

Or manually:
  sysctl -w net.ipv6.conf.all.disable_ipv6=0

---

ISSUE: Need to check status
━━━━━━━━━━━━━━━━━━━━━━━
  network-config status
  
Or use full menu:
  ipv6-menu
  [Select option 1]

---

ISSUE: Want to see configuration log
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
View with:
  cat ~/.config/termux-ipv6/ipv6.log

Or use menu:
  ipv6-menu
  [Select option 5]
